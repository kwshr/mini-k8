cli package:
json.Marshal(payload) - converts the payload to raw bytes
bytes.NewReader(body) - wraps the raw bytes so it can be used as a stream, so that http.Post can read it chunk by chunk
Why does http.Post need a Reader?
For large payloads, you don't want to load everything into memory at once. A Reader lets you stream it.
